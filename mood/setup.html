Mood Logger setup

  1. Copy the backend code.
  2. Open Apps Script. On a phone, tap ⋮ → Desktop site in Chrome if the editor looks broken. Open new Apps Script project
  3. Select everything in the editor, paste over it, and tap the save icon.
  4. Tap Deploy → New deployment. Pick the type Web app, set Execute as: Me and Who has access: Anyone, then tap Deploy.
    Google will ask you to authorize. If it shows "Google hasn't verified this app", choose Advanced → Go to project. It's your own script.
  5. Open the Web app URL it shows you, then tap Connect Mood Logger. The app opens already connected.
  6. In the app, tap ⋮ → Add to Home screen. That's it.
